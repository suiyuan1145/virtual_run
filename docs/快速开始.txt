虚拟跑步 1.4.3 — Windows 完整软件包

一、打开软件
完整解压 ZIP 后，双击“虚拟跑步.exe”。
独立版“虚拟跑步-1.4.3-Windows.exe”可以直接双击，无需手动解压。
首次正常打开 EXE 自动创建桌面“虚拟跑步”图标和开始菜单入口。
同时登记到 Windows“已安装的应用”，开始菜单提供卸载入口。
以后从快捷方式打开即可；软件“设置”可重新创建快捷方式。
程序安装在个人数据目录的固定版本目录，移动下载的 EXE 或 ZIP 解压源目录不影响快捷方式。
内置 Python、原版安小信 APK、晨跑脚本及帮助文档。
首次 Android 模拟器和镜像需在软件“首次安装”中联网下载。

二、首次设置
1. 在“首次安装”准备环境、安装内置原版 APK。
2. 先使用可见模拟器，完成隐私和定位权限提示。
3. 在“晨跑与登录”手动填写账号、密码并登录。
   如需自动重新登录，勾选加密保存登录信息。
4. 读取 GPS 起点，确认安小信地图位置正确。
5. 点击“立即试跑 60 秒”，验证自动开始、移动和结束。
6. 点击“保存并启用每日晨跑”。

三、晨跑参数
默认北京时间 06:55 准备，07:00 开始，08:00 结束。
默认速度 12 km/h，环形半径 150 米，可在界面修改。
启用任务后无需保持软件窗口打开；电脑必须开机、不休眠且 Windows 已登录。

四、后台无窗口
首次配置完成后可勾选“后台运行模拟器”，保存或启用晨跑。
只在模拟器下次启动时生效；已有模拟器不会被自动关闭或重启。
如果已有窗口，先结束记录、正常关闭模拟器，再启动任务。
无窗口时仍通过 ADB 操作安卓内部界面；模拟器进程必须持续运行。
需要恢复窗口时，先停止任务并结束记录，点击“关闭模拟器”，再取消勾选并启动。
关闭按钮只作用于指定模拟器；晨跑任务仍运行或跑步页面未退出时会拒绝关闭。

五、停止与日志
“停止当前操作”停止本窗口启动的任务并尝试结束它创建的记录。
“停用每日晨跑”只停用未来任务，不中断正在执行的晨跑。
“打开配置与日志”可查看个人配置和运行结果。
完整步骤在软件“使用指南”“README”“启动与登录”页，按 F1 打开使用指南。

60 秒试跑只验证流程；完整一小时及服务端有效运动判定仍需实测。

六、卸载软件
先停止晨跑并关闭软件。
在 Windows“已安装的应用”（Windows 10“应用和功能”）中找到“虚拟跑步”卸载。
也可使用开始菜单“卸载虚拟跑步”，或软件“设置 → 卸载软件”。
默认移除程序、自己的快捷方式、应用登记和本安装的晨跑任务，保留配置、密码及日志。
卸载窗口可勾选额外清除本工具的个人数据。
Android SDK、镜像、虚拟机及安小信的登录状态保留；下载的 EXE、ZIP 解压源目录也保留。


一键停用：晨跑与登录页的按钮在任务运行时也可使用。取消当前登录、检查、试跑或定位操作，停用后续每日晨跑，等待本工具创建的记录结束与后台进程退出，然后关闭指定模拟器。配置和账号保留。若记录结束未确认，会报告原因并保留模拟器，需人工检查。再次点击试跑可恢复手动运行；定时晨跑需重新点击“保存并启用每日晨跑”。关闭软件不会自动停用每日任务。

智慧运动入口按 UI 层级寻找可点击的父控件；不点击不可交互的页面标题。同一入口最多尝试两次，页面不变化会停止并报告原因。
