# 虚拟跑步 1.4.8：自动点击按钮专项测试

先启动官方模拟器，在安小信登录自己的账号，结束已有跑步记录，并停止其他软件的定位发送。

双击“测试自动点击跑步.cmd”。未连接时会启动已经配置好的官方模拟器。脚本检查指定的 VirtualRun_API30，找到“开始运动”并点击，确认进入“运动中”，等待约 20 秒后自动暂停、长按结束并处理短记录确认。

本测试默认使用模拟器当前 GPS，不发送跑步路线。重启后没有 GPS 时，可使用 --origin 纬度 经度 指定已确认的 WGS84 起点，脚本会在点击开始前静止准备 15 秒。测试记录很短，可能出现“无法保存记录”；脚本会点击“结束”，而不是“继续运动”。按钮测试成功不代表跑步里程有效或服务端认可记录。

遇到已有记录、需要登录、定位异常或无法识别界面时会停止，并保存结果。不会操作 USB 手机，不会接管已有记录。测试过程中按 Ctrl+C 会请求结束本次创建的记录。

日志、界面 XML、截图和 result.json 位于 %LOCALAPPDATA%\VirtualRunDesktop\click-tests。start_confirmed 表示已确认运动中；finish_confirmed 表示已确认结束。结束失败时需检查模拟器并手动结束。

只读检查可运行：runtime\python.exe -X utf8 click_run_test.py --check

可用 --avd 指定其他官方模拟器名称，用 --sdk 指定 SDK 路径。--hold-seconds 支持 1–60 秒，默认 20 秒。本测试不会启用或停用每日晨跑任务。

## 实测结果

2026 年 10 月 8 日在 VirtualRun_API30、安小信 2.0.5 x86 实测：自动进入智慧运动和随性跑步，点击开始运动，确认运动中，等待约 20 秒，自动暂停、长按结束，并在短记录弹窗点击结束。结果页显示 0 公里、0 km/h、00:00:23，以及“本次运动低于1公里，故无效”。这次短时测试只验证按钮自动操作。后续定时流程的当前验证范围见 README 与晨跑使用说明；平台有效性仍需在原应用核对。
