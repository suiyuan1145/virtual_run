# 虚拟跑步 1.4.6 使用指南

独立版双击“虚拟跑步-1.4.6-Windows.exe”即可使用全部功能；首次自动准备内置文件。ZIP 版需完整解压后双击“虚拟跑步.exe”。

首次正常打开 EXE 会创建桌面“虚拟跑步”快捷方式，并添加开始菜单“虚拟跑步”和“使用说明”入口。以后直接使用快捷方式。“设置”中可重新创建桌面快捷方式或开始菜单入口。快捷方式使用个人数据目录中的固定程序文件，移动下载的 EXE 或 ZIP 解压源目录不影响它们；不要删除 app 中实际运行的版本目录。

## 安装登记与卸载

正常打开新版 EXE 后，软件会显示在 Windows“已安装的应用”（Windows 10“应用和功能”）中，包含版本和卸载入口。开始菜单也有“卸载虚拟跑步”；软件“设置 → 卸载软件”会关闭本窗口并打开原生卸载向导。

默认卸载程序文件、自己的快捷方式、应用登记和本安装的晨跑任务，保留个人配置、密码和日志。卸载窗口勾选额外清除个人数据后，会清除本工具保存的凭据和日志。SDK、镜像、虚拟机及其登录状态不删除。先停止晨跑并关闭软件；正在运行的任务或重定向路径会阻止卸载。

新电脑先进入“首次安装”自动准备 Android 环境。完整包已带安小信 APK 和 Python；登录步骤见“启动与登录”页面。

## 晨跑与登录页面

账号和密码由本人手动填写，点击“登录安小信”启动指定的官方模拟器并登录。密码框默认隐藏，登录成功后清空输入框。首次隐私、权限或验证码提示需在模拟器中处理。

勾选“为晨跑保存登录信息”后保存，晨跑遇到账号密码登录页会自动提交一次。账号密码使用当前 Windows 用户的 DPAPI 加密保存，个人文件为 morning/login.dat；不会放进普通配置、日志或软件包。取消勾选并保存会清除保存的登录信息。保存的密码不自动显示回输入框；留空时使用当前账号已经保存的密码，修改账号则需重新填写密码。

软件默认打开此页。点击“读取当前 GPS 起点”自动启动并选择设置中的模拟器，读取当前系统坐标；不点击运动按钮，也不发送位置。确认应用地图位置正确后设置速度、半径。可选点击“立即试跑 60 秒”验证流程，或直接保存并启用每日任务。试跑、执行定时脚本、启用每日晨跑都会先保存当前填写的参数，无需额外点击保存。修改参数不会改变已经运行中的任务。

“后台运行模拟器”使用官方无窗口启动模式。首次登录、权限和地图确认先取消勾选，完成后再启用后台选项并保存或启用晨跑。只影响下次启动；已运行的模拟器保留原状态，不会自动重启。已有窗口时，先结束记录并正常关闭模拟器，下一次再后台启动。电脑须保持运行；无窗口不代表关闭了模拟器。

“关闭模拟器”只关闭设置中指定的 AVD。晨跑任务未退出或检测到打开的跑步页面时会拒绝关闭，避免中断记录。后台模式需要恢复窗口时，先停止任务并结束记录，点击“关闭模拟器”，取消后台勾选，再点击“读取当前 GPS 起点”启动。

- 保存并检查环境：只读检查，报告当前是否需要登录，不开始运动。
- 立即试跑 60 秒：立即自动开始、发送路线并结束，适合验证，不影响当天定时状态。
- 保存并启用每日晨跑：保存当前参数和登录设置，每天北京时间 06:55 准备、07:00 开始、08:00 结束。
- 执行今天的定时脚本：立即调用定时脚本；当天 06:50–07:01 之外会跳过。
- 停用每日晨跑：停用后续计划任务，不中断已开始的记录。
- 停止当前操作：停止从本窗口启动的登录、试跑或定时脚本，尝试结束自己创建的运动记录。
- 打开配置与日志：查看个人配置、daily-state.json、试跑结果、坐标与截图。

电脑需保持开机且 Windows 用户已登录；启用计划任务后可关闭软件窗口。密码错误、验证码、网络或定位异常会停止；已有记录不会被接管。首次定位权限需手动完成，已识别的系统电池优化提示会自动关闭。自动输入适用于已识别的安小信 2.0.5 账号密码页；含中文、空格或字面 %s 的密码需在模拟器里手动登录。

## 跑步测试：一键运行

首次先在可见模拟器中安装安小信，完成自己的账号登录、隐私和定位权限。之后无窗口模式也能自动点击开始和结束，不需要桌面显示模拟器。

在“跑步测试”填写速度、运动时长和半径，点击“一键开始测试”。无需填写纬度、经度，也不用先读取地址或手动点击开始。

- 速度：0.5–30 km/h，默认 12。
- 运动时长：1–3600 的整数秒，默认 60；指移动轨迹的发送时间，准备及结束另需时间。
- 半径：10–10000 米，默认 150；一般保留默认值即可。

程序自动选择设置中的官方 AVD，必要时启动它，进入“开始运动”页并读取当前 GPS。读取成功后静止准备约 15 秒，再自动开始并发送路线，到时结束自己创建的记录。

如果应用只在运动中请求定位，程序先自动开始该条新记录，再等待 GPS 并静止准备，之后发送移动轨迹。此时准备时间会计入应用时长。GPS 不可用时不猜测起点，会尝试关闭自己创建的记录并报告失败。

“停止并结束本次测试”停止位置移动，尝试结束该条记录并回收脚本进程。再次开始会创建新记录，不继续旧记录。软件不会接管已有手动记录；请先结束旧记录并返回首页或“开始运动”页。

测试期间预览显示实际发送的轨迹；可在结束后导出。配置和结果保存在个人数据目录的 morning 下，即时参数文件为“即时测试配置.json”，结果位于 logs 中的 trial-result.json、track.jsonl 和截图。它与每日晨跑共用互斥锁，但不覆盖每日晨跑配置、当天状态或 Windows 任务。

在“晨跑与登录”保存的自动登录设置也用于测试；账号密码只保存在本机。首次权限、隐私和验证码仍须手动处理。读取不到位置、入口不能加载或无法确认结束时查看日志，不代表已保存有效运动。

## 常见问题

找不到设备：等待模拟器启动完成，再刷新；确认 Android 系统已开机。

打开安小信失败：先确认已安装应用。需要安装时点击“安装原版 APK”，选择原始文件，.apk.1 也可选择。不要在正常使用时反复安装。

速度或里程异常：先确认模拟器当前位置，结束旧记录后重新一键测试。工具不能清除应用已累计的异常里程。

提示 GPS 距起点过远：先停止应用记录，重新读取位置和准备起点。软件会取消该次发送，避免突然跳变。

提示第三方模拟器不支持：当前软件采用官方 Android Emulator 的控制接口。切换到已准备的官方模拟器。

轨迹动了但应用不更新：确认已进入智慧运动页面，Android 定位开启，应用获得定位权限，再观察应用地图和运动数据。发送命令成功和应用采用定位是两个不同的验证结果。


一键停用：晨跑与登录页的按钮在任务运行时也可使用。取消当前登录、检查、试跑或定位操作，停用后续每日晨跑，等待本工具创建的记录结束与后台进程退出，然后关闭指定模拟器。配置和账号保留。若记录结束未确认，会报告原因并保留模拟器，需人工检查。再次点击试跑可恢复手动运行；定时晨跑需重新点击“保存并启用每日晨跑”。关闭软件不会自动停用每日任务。

智慧运动入口按 UI 层级寻找控件，不点击不可交互的页面标题。点击后等待加载，重复点击至少间隔 20 秒。首页长期无响应时恢复入口一次；已启用自动登录时，通过原版登录界面重新登录一次，再等待运动页面加载。未启用自动登录时不会提交保存的密码。

60 秒试跑用于验证，不是每日晨跑的必要步骤。入口准备超时且从未尝试开始时，可在启动窗口内最多准备三次；一旦尝试开始、已有记录、用户取消或达到次数上限，当天不再自动创建记录。07:01 后不补跑。

## 查看后台模拟器

点击“晨跑与登录”页的“查看后台画面”，可查看当前 Android 屏幕，每两秒刷新一次。预览按钮在操作进行中也可使用，关闭预览只停止读取屏幕。预览是只读的，不能点击 Android 按钮，不会发送位置或保存截图。

需要手动处理提示时：先正常结束已有跑步记录并停止任务 → 点击“关闭模拟器” → 取消“后台运行模拟器” → 点击“读取当前 GPS 起点”重新启动可见窗口。已有记录或任务未退出时，不会关闭模拟器。

停在“结束运动”结果页时无需重新填写密码。登录按钮会识别当前页面；未知权限、隐私或验证码提示仍需在窗口中处理。登录检查结束后会在个人日志目录保存现场，方便诊断。
