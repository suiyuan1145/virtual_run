# 虚拟跑步 1.4.6

Windows 桌面路线模拟与 Android 定位测试工具。通过官方 Android Emulator 和 ADB 操作原版安小信，提供一键跑步测试、每日定时任务、自动登录和后台画面预览。

已测试的应用为安小信 2.0.5 / x86，包名 cn.edu.aiit.axx；默认虚拟设备为 Android 11 / API 30 的 VirtualRun_API30。电脑版本与独立 Android 应用的版本分别管理。

## 主要功能

- 一键跑步测试：填写速度、移动时长和半径，自动读取起点、开始、发送路线并结束。
- 每日晨跑：06:55 准备，07:00–08:00 运行。60 秒试跑用于验证，不是定时任务的前置条件。
- 自动登录：使用原版账号密码登录页，识别已打开的首页、运动页和结束结果页。
- 查看后台画面：每两秒刷新指定模拟器的屏幕，只读查看，不发送触摸或定位。
- 入口恢复：等待页面加载，仅尚未尝试开始的入口超时允许有限重试，避免重复记录。
- 一键停用：取消当前操作、停用后续任务，确认结束本工具创建的记录后关闭指定模拟器。
- Windows 集成：桌面与开始菜单快捷方式、应用登记和卸载器。

## 安装与数据

完整 EXE 自带 Python、Tcl/Tk、ADB、说明与用户提供的原版 APK。首次 Android 环境可在软件中联网下载。直接打开“虚拟跑步-1.4.6-Windows.exe”，或完整解压 ZIP 后打开“虚拟跑步.exe”。

设置、个人晨跑配置和日志默认保存在 %LOCALAPPDATA%\VirtualRunDesktop。勾选保存后，账号密码通过当前 Windows 用户的 DPAPI 加密到 morning/login.dat；个人数据不进入软件包。

即时测试与每日任务使用同一互斥锁，配置分别保存。已有手动记录不会被接管。卸载默认保留个人数据和 Android SDK、镜像、虚拟设备。
