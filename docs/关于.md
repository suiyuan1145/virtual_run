# 虚拟跑步 1.4.3

Windows 桌面定位测试软件，针对本机官方 Android Emulator 中的安小信智慧运动进行路线模拟。

本机测试应用：安小信 2.0.5，包名 cn.edu.aiit.axx。
本机虚拟设备：Android 11 / API 30，VirtualRun_API30。

## 软件组成

Python / Tkinter 提供桌面界面，完整软件包自带 Python、Tcl/Tk 和 ADB。解压后通过“启动虚拟跑步.cmd”启动，无需另行安装 Python。ADB 与模拟器通信；运行时优先使用已配置 SDK 的 ADB，找不到时使用随包备用版本。

软件包含用户提供的原版安小信 2.0.5 APK、启动登录教程和每日晨跑脚本。“首次安装”页面自动从 Google 官方源下载 Android 模拟器、Platform Tools 和 Android 11 镜像，校验后创建虚拟设备；首次配置需要联网。

“晨跑与登录”可配置每天 07:00–08:00 的自动任务，默认速度 12 km/h、半径 150 米。每位使用者需登录自己的账号、设置自己的起点并启用任务。应用保持原版安装，软件通过模拟器公开接口发送测试位置。

## 数据保存

设置和日志保存在 %LOCALAPPDATA%\VirtualRunDesktop。进入“设置”可打开数据目录。轨迹文件保存到导出时选择的位置。

“晨跑与登录”提供手动输入账号密码及自动登录按钮。仅在勾选保存后，通过 Windows DPAPI 加密保存登录信息到 morning/login.dat；只可由本机当前 Windows 用户读取。不把明文密码写入配置、日志或分发包，取消勾选并保存可删除已保存信息。

跑步测试的起点不作为启动设置保存；启用晨跑时，个人起点会保存在数据目录的 morning/晨跑配置.json。分发包包含运行所需脚本，不携带账号密码、虚拟设备用户数据、个人晨跑配置或已启用的任务。APK 分析证据和个人测试日志不包含在分发包中。
