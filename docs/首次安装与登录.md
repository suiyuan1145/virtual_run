# 虚拟跑步 1.4.6：首次安装与登录

完整包面向 Windows 10/11 x64 的 Intel/AMD 电脑。每位使用者登录自己的账号，并确认自己的测试起点。

## 打开软件

直接双击“虚拟跑步-1.4.6-Windows.exe”，无需解压或另装 Python、Java、Android Studio。首次准备内置文件，创建桌面、开始菜单和卸载入口。

ZIP 版完整解压到“虚拟跑步-1.4.6”，双击“虚拟跑步.exe”，也可使用“启动虚拟跑步.cmd”。不要在压缩包内运行。程序准备到 %LOCALAPPDATA%\VirtualRunDesktop\app 的固定目录，后续可以从快捷方式打开。

## 准备 Android 环境

进入“首次安装”，确认 SDK 目录，留出至少 12 GB 磁盘空间。阅读 SDK 许可，同意后点击“自动下载安装环境”。软件从官方源下载模拟器、Platform Tools 和 Android 11 / API 30 Google APIs x86_64 镜像，校验后创建 VirtualRun_API30。

首次下载约 1–2 GB，以界面显示为准。已有环境可在“设置”选择 SDK 与 AVD，不必重复下载。网络需要代理时，填写自己已运行的 HTTP 代理地址；软件不安装代理。

首次登录先取消“后台运行模拟器”，点击“启动模拟器”或“读取当前 GPS 起点”，等待开机。刷新设备并选择 emulator- 开头的官方模拟器。硬件虚拟化不可用时，按 Android 官方说明配置电脑后再启动。

## 安装并登录安小信

点击“安装原版 APK”，使用完整包中的安小信.apk 或自己取得的原始安装包。本项目测试的是安小信 2.0.5 / x86。已经安装时不必重复安装。

打开安小信，先手动完成隐私、权限和学校选择。对于已识别的账号密码登录页，在电脑“晨跑与登录”输入账号、密码，点击“登录安小信”。这个按钮不开始运动。

如需自动重新登录，勾选“为晨跑保存登录信息”并保存。信息通过当前用户的 Windows DPAPI 加密；换电脑或 Windows 用户需重新填写。验证码、其他登录方式和含中文、空格或字面 %s 的密码，请在模拟器中处理。

已经停在首页、运动页或“结束运动”结果页时，程序会识别当前页面并避免重复提交。页面识别不等于重新验证服务器令牌。

## 查看后台提示

点击“查看后台画面”，每两秒刷新当前 Android 屏幕。预览只读，不点击按钮、不发送位置、不重启设备，也不保存截图。

需要手动处理提示时，先结束已有记录并停止操作，点击“关闭模拟器”，取消“后台运行模拟器”，再点击“读取当前 GPS 起点”启动可见窗口。只取消勾选不会让正在运行的无窗口模拟器立即出现窗口。

## 一键测试与每日晨跑

“跑步测试”只需填写速度、运动时长和半径，然后点击“一键开始测试”；无需填写经纬度或手动点击安小信。时长为发送移动轨迹的时间，范围 1–3600 整数秒。准备和结束另需时间。

每日任务在“晨跑与登录”配置。读取并核对自己的 WGS84 起点，填写速度和半径，保存并检查环境后点击“保存并启用每日晨跑”。不要直接使用模拟器美国默认位置，也不要把百度 BD-09 数值当成 WGS84。

每日北京时间 06:55 准备、07:00 开始、08:00 结束，默认速度 12 km/h、半径 150 米。电脑需开机、Windows 用户已登录、网络和定位可用。60 秒试跑是可选验证，不是晨跑的必要步骤。

只有未尝试开始的入口超时会在启动窗口内最多准备三次；已尝试开始、已有记录、用户取消或达到上限时，当天不会重复创建记录。07:01 后不补跑。

“停用每日晨跑”停用后续任务；“一键停用”还会取消当前操作并尝试结束本工具创建的记录。重新使用定时任务需点击“保存并启用每日晨跑”。查看个人 logs 和 daily-state.json 核对结果。
