# 首次安装、启动与登录安小信

完整包面向 Windows 10/11 的 64 位 Intel/AMD 电脑。包含 Python 运行环境、安小信 2.0.5 原始 APK、定位工具、晨跑脚本和本教程。每个人登录自己的账号。

## 1. 解压并打开

推荐直接双击“虚拟跑步-1.4.2-Windows.exe”。首次自动准备内置运行环境、APK 和晨跑脚本，后续直接打开程序。无需手动安装 Python、Java 或 Android Studio。

若使用 ZIP，完整解压后进入“虚拟跑步-1.4.2”，双击“虚拟跑步.exe”；也保留“启动虚拟跑步.cmd”。不要直接在压缩包里运行。独立 EXE 将程序文件保存在 %LOCALAPPDATA%\VirtualRunDesktop\app 下；晨跑任务使用该固定目录中的运行环境，不依赖临时解压目录。

首次正常打开会创建桌面“虚拟跑步”图标，并添加开始菜单程序和使用说明入口。ZIP 版也会准备固定程序目录，以后可直接从快捷方式打开，无需保留下载的 EXE 或解压源目录。“设置”可重新创建快捷方式。

## 2. 自动准备 Android 环境

进入“首次安装”。默认安装目录是当前用户 AppData\Local\Android\Sdk，也可更换。磁盘至少留出 12 GB 空间。

点击“查看许可”阅读 Android SDK 许可；同意后勾选，点击“自动下载安装环境”。程序从 Google 官方源下载稳定版模拟器、Platform Tools、Android 11 / API 30 Google APIs x86_64 镜像，校验后创建 VirtualRun_API30。首次需联网下载约 1–2 GB，界面显示实际大小；以后无需重新下载。

网络无法连接 Google 时，在代理栏填写自己的 HTTP 代理地址，例如 http://127.0.0.1:7897。代理服务需已经运行，软件不安装代理。留空使用系统网络设置。下载中断后可重试续传。已有虚拟设备及登录数据不会被覆盖。

## 3. 启动模拟器

点击“启动模拟器”，等待安卓桌面出现，再点击“刷新设备”，选择 emulator- 开头的设备。电脑路线不选择 USB 手机。

若提示硬件加速不可用，按 Android 官方教程启用 CPU 虚拟化及 Windows Hypervisor Platform，可能需重启。软件不会自动修改 BIOS 或系统虚拟化功能。参考：https://developer.android.com/studio/run/emulator-acceleration

## 4. 安装内置安小信 APK

选择模拟器，点击“安装安小信”或“安装原版 APK”。软件使用包内“安小信.apk”，为此版本选择 x86 安装方式。看到 Success 表示成功。已经安装时无需重复安装。

APK 与用户提供的原文件一致，未修改，不包含账号或运动记录。

## 5. 登录自己的账号

点击“打开安小信”。首次出现隐私说明或权限提示时，按应用要求设置，并允许必要定位权限。选择自己所属学校或登录方式。

对于安小信 2.0.5 的原版账号密码登录页，可进入电脑版“晨跑与登录”，手动填写账号和密码，点击“登录安小信”。软件使用“设置”中指定的 AVD，只登录、不开始跑步。已经登录时无需重复提交。密码错误、网络异常或验证码提示会停止，需在模拟器中处理。

若需要晨跑自动重新登录，勾选“为晨跑保存登录信息”，点击“保存登录设置”。账号密码经 Windows DPAPI 加密，保存在个人数据目录 morning/login.dat，不写入 ZIP、普通配置或日志；换电脑或 Windows 用户需重新填写。取消勾选并保存会清除已保存信息。不勾选时，登录按钮仅使用这次手动输入，晨跑要求应用保持登录。

不同学校的其他登录页、验证码登录、含中文、空格或字面 %s 的密码，请在模拟器里手动完成。

进入安小信主页，打开“智慧运动”。右上角白色跑步小人 → 随性跑步 → 开始运动，才会进入实际跑步定位界面。智慧运动首页的任务卡片不输出跑步定位日志。“开始运动”会进入记录流程，不是只预览地图。

## 6. 准备正确起点

新虚拟机可能在美国默认位置。先在跑步测试页输入自己的 WGS84 起点，点击“准备起点（15 秒）”；此时不要记录运动。准备完成后才在安小信开始新记录。

如果已经在运动界面，可以读取安小信位置；随后先结束该条准备记录，再准备起点并开始新记录。也可读取系统 GPS，但需要核对是否仍为美国默认坐标。国内百度地图通常使用 BD-09，软件读取时会转换为 WGS84，不要把 BD-09 数值直接当作 WGS84。

## 7. 设置每日晨跑

进入“晨跑与登录”，填写并确认 WGS84 起点，或从跑步测试复制起点。默认 12 km/h、150 米半径。点击“保存晨跑配置”或“保存并检查环境”，通过后点击“保存并启用每日晨跑”。每个人都需要启用自己的任务；解压软件不会自动登记或运行晨跑。

“立即试跑 60 秒”随时进行短时验证，不影响当天定时状态。“执行今天的定时脚本”按保存的定时参数执行，在 06:50–07:01 以外会跳过。“停止当前操作”会停止本窗口启动的试跑或定时脚本，并尝试结束它自己开始的记录。

每天北京时间 06:55 准备、07:00 开始、08:00 停止并结束。电脑需开机、当前用户已登录、安小信保持登录且网络可用。已有旧记录、登录失效或位置异常会跳过或停止。完整一小时自动流程及服务端接受尚未验证，首次运行后查看运动结果和日志。

点击“停用每日晨跑”可停用未来任务。移动软件目录前先停用，移动后从新位置重新启用，更新运行环境路径。
