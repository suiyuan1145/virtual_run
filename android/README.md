# 虚拟跑步 · Android 1.0.0

可安装在 Android 8.0 及以上设备的 APK。应用通过 Android 官方模拟位置接口，按指定起点、速度和圆形路线发送测试定位。

## 安装与使用

把“虚拟跑步-Android-1.0.0.apk”传到手机，点击安装。首次从文件管理器安装时，按系统提示允许该文件管理器安装应用。

安装后打开“虚拟跑步”，授予精确定位权限，并在系统开发者选项的“选择模拟位置信息应用”中选择本应用。Android 13 及以上建议允许通知，以便查看测试状态和暂停。

完整操作见应用内“使用指南”：读取系统位置 → 准备起点 15 秒 → 在安小信开始新记录 → 回到本应用开始测试 → 倒计时结束后发送路线。

## 功能

- 读取近期真实系统定位作为 WGS84 起点，或手动输入坐标。
- 设置半径、速度、时长和开始倒计时。
- 前台服务持续发送位置，切换到安小信后继续运行。
- 环形轨迹预览、暂停、从终点继续、明确恢复真实定位。
- 导出包含坐标、时间和距离的 JSON 轨迹。
- 内置使用指南和 README，保存速度、半径等设置。

默认速度 6 km/h，半径 150 米，单段时长 30 秒，开始倒计时 10 秒。先用短段测试定位是否被目标应用采用。

## 安卓版与电脑版的区别

安卓版使用系统模拟定位，坐标带有 Android 的测试标记。安小信的定位 SDK 可能拒绝这些坐标；电脑版在模拟器中成功，不能证明手机上也会接受。应用不修改安小信，不隐藏模拟位置标记。

普通安卓应用无法读取另一应用的内部日志，因此安卓版从系统定位读取起点，不能自动提取安小信内部定位日志或账户地址。请在安小信地图核对起点。

本应用未使用网络权限，不要求 root，不需要 Windows 或 Python。安小信需要独立安装。软件不会自动点击安小信的开始、结束或提交操作。

## 后台与数据

正在发送或倒计时时，前台服务和局部唤醒锁维持任务。暂停或本段结束后，保持终点并发送零速度，避免立即跳回真实位置。用户在安小信结束记录后，再点击“恢复真实定位”。通知栏也提供暂停和恢复按钮。

划掉界面不会主动结束前台服务；部分手机的省电策略可能终止服务。通过“应用系统设置”查看电池限制。系统或用户强制停止应用后，重新打开需要重新准备起点，不会自动恢复旧路线。

轨迹保存于本应用私有目录；导出使用 Android 系统文件选择器，无需存储权限。卸载会删除私有轨迹和设置。不会把坐标自动上传到服务器。

## 构建与签名

源码：android/src/com/virtualrun/android。
构建：python android/build_apk.py。
构建参数：--sdk 指定 SDK 目录；--java 指定 JDK 目录。
要求：SDK Platform 35、Build Tools 36.0.0、JDK 21、Python 3。

使用官方 aapt2、javac、D8、zipalign 和 apksigner，不需要下载 Gradle 或第三方库。输出位于 dist/android。

本地签名密钥保存在 android/signing，未放入 APK 分发目录，也被版本控制忽略。后续升级须保留该目录并使用相同签名；不要公开密钥。
